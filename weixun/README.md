# 微醺局

线下围坐一桌的酒桌小游戏,手机竖屏,全中文。线上地址:**https://weixun.wawazhiliao.com**

| 游戏 | 手机 | 玩法 |
| ---- | ---- | ---- |
| 🤔 我是谁 | 每人一部(或一部传看) | 每人一个词,别人看得到自己看不到,问「是 / 不是」来猜 |
| 🙆 你比我猜 | 一部 | 60 秒比划,合作猜对 5 个过关 |
| 🤫 禁忌动作 | 每人一部(或一部传看) | 每人一个禁忌自己不知道,被诱导触发就出局 |
| 🕵️ 谁是卧底 | 每人一部(或一部传看) | 每部手机只显示自己的词,描述 → 投票 → 找卧底 |

惩罚单位统一是「口」,每人每轮最多 2 口,一轮结束才结算一次。

## 多人同步是怎么做的

**发词完全不靠后端**:每部手机输入同一个「房间码 + 轮数 + 人数」,用它们做随机种子,在本机算出每个座位的词([public/js/deal.js](public/js/deal.js))。所以所有手机算出的结果一样,每部手机只是把自己那个座位藏起来(我是谁 / 禁忌),或者只显示自己那个(卧底)。顶栏的「校验码」是整轮发词结果的指纹,大家对一眼就知道是否对齐。

同一房间内不重复:用房间码把整副词库洗一遍,第 r 轮取第 r 段,用完一整副再换一种洗法。

**可选的小后端**([src/room.js](src/room.js),Cloudflare Durable Object,一个房间码一个)只存需要大家共享的东西:

- 房主(先认领先得)和房主的自定义词库 —— 房主在「📝 词库」里改词,保存后同步给全房间
- 房主给某个座位「🔄 换」一个词或「✏️ 改」成指定的词
- 座位昵称、谁已经猜中/中招/出局、禁忌动作的共享倒计时、结算时谁指定谁

连不上后端时(比如部署在 GitHub Pages / Vercel 静态站),自动退回本地模式:照样能玩,用内置词库,只是上面这些不同步。

## 改词

- 内置词库在 [public/data/](public/data/):`who.js` 我是谁(按类别分组)、`charades.js` 你比我猜(简单/普通/离谱)、`taboo.js` 禁忌动作、`spy.js` 谁是卧底(词对)。直接往数组里加字符串即可。
- 也可以在网页的「📝 词库」里改(一行一个词),存在自己手机上;当了房主就会同步给房间里所有人。
- ⚠️ 改了内置词库后部署,大家要刷新页面拿到新版本,否则校验码会对不上。改了 `data/` 或 `js/` 记得把 `index.html` 里对应的 `?v=` +1。

## 本地开发 / 测试 / 部署

```bash
../dao/node_modules/.bin/wrangler dev --port 8792   # 本地起服务
node test/deal.mjs                                   # 发词一致性 + 不重复 + 词库规模
node test/api.mjs                                    # 房间接口(BASE=线上地址 可测线上)
../dao/node_modules/.bin/wrangler deploy             # 部署到 weixun.wawazhiliao.com
```

纯静态部署也行:把 `public/` 目录丢到 GitHub Pages / Vercel 即可(没有房主同步功能)。
