# 仄梦的岛屿开拓

2~4 人六边形资源开拓联机桌游,开房间和朋友在浏览器里玩:**https://dao.wawazhiliao.com**

纯前端(SVG)+ Cloudflare Workers + Durable Objects(WebSocket 房间制),无框架、零构建。
名字、文案、美术全部原创。

## 玩法速览

在仄梦群岛上开拓定居,率先攒到目标分数(默认 10 分)的人获胜。

- **五种资源**:灵木、陶土、稻穗、云绢、辉石,由骰子点数对应的地格产出,村庄拿 1 张、城邑拿 2 张;银行每种只有 19 张,不够分时按短缺规则处理。
- **建造**:道路(灵木+陶土)、村庄(灵木+陶土+稻穗+云绢,1 分)、城邑(2稻穗+3辉石,2 分)、发展卡(云绢+稻穗+辉石)。村庄要满足间隔规则且连着自己的路。
- **掷出 7**:手牌超过 7 张的玩家弃掉一半,当前玩家移动强盗封锁一格并偷 1 张牌。
- **发展卡**:骑士(移强盗偷牌,凑最大军团)、胜利点(保密 1 分)、垄断、筑路、丰收;每回合限打 1 张,当回合买的不能打。
- **称号**:最长路(连续 ≥5 段最长者 +2 分)、最大军团(骑士 ≥3 张最多者 +2 分),都会被超越转移。
- **交易**:当前玩家可与其他玩家自由谈判(发起报价、接受/拒绝/还价);与银行默认 4:1,建筑落在港口可享 3:1(通用港)或 2:1(专属港)。
- **机器人**:大厅可添加 🤖 陪练,自动放置、建造、交易、应对强盗,方便单人测试。

## 本地开发

```bash
npm install
npx wrangler dev
```

浏览器开多个标签页即可模拟多人。测试:

```bash
node test/sim.mjs 40   # 无头模拟:随机 AI 整局回归(不需要起服务)
node test/e2e.mjs      # 端到端:走真实 WebSocket 三人整局(需先起 wrangler dev)
```

部署:`npx wrangler deploy`

## 结构

```
src/worker.js          Worker 入口:静态资源 + /api/create + /ws 路由到房间 DO
src/room.js            GameRoom(Durable Object):权威游戏引擎与广播
public/js/shared/      前后端共用:六边形几何、棋盘生成、规则判定
public/js/app.js       界面状态机 + WebSocket 客户端
public/js/render.js    SVG 棋盘渲染
```
