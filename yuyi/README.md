# 余一

2~6 人类 UNO 快节奏纸牌联机游戏,开房间和朋友在浏览器里玩:**https://yuyi.wawazhiliao.com**

纯前端 + Cloudflare Workers + Durable Objects(WebSocket 房间制),无框架、零构建。
名字与卡面均为原创;玩法机制对齐 UNO 官方基础规则。

## 玩法速览

- 108 张牌:四色(赤/金/翠/黛)数字 0~9 与 禁牌/反转/+2,另有 换色×4、+4换色×4。
- 对上**颜色或数字/符号**即可出牌;出不了(或不想出)就摸一张,摸到能打的可立即打出。
- 手里只剩一张时要喊「**余一!**」——被人抓到没喊,罚摸 2 张。
- 「+4换色」只有在没有当前颜色手牌时才是合法打出;被 +4 的玩家可以**质疑**:对方违规则对方自摸 4 张,质疑失败自己摸 6 张。
- 2 人局中「反转」等同于「禁牌」。
- 有人清空手牌即赢下本局,按其余玩家的余牌计分(数字=面值,功能牌 20,万能牌 50);积分赛先到目标分获得最终胜利,也可选单局定胜负。
- 大厅可添加 🤖 机器人陪练。
